- 게임 폴더: `D:\야겜\Zombie's Retreat 2 v1.1.0 .손번역 by 아티팩트` (RPG Maker MV, 데이터는 `www\data`)
- 프로필: `profiles/zombies_retreat_2.js`

## 설치

1. `dist/zombies_retreat_2/ClaudeAutoNav_v3.js` → `www\js\plugins\`에 복사
2. `www\js\plugins.js`를 백업한 뒤 메모장으로 열고, 마지막 항목 뒤에 다음 줄 추가 (앞 항목 끝에 `,` 필요)
   `{"name":"ClaudeAutoNav_v3","status":true,"description":"자동 내비게이션","parameters":{}}`
3. 게임 재시작 후 맵에서 N 키

업데이트할 때는 버전 번호를 올려 빌드(`node tools/build.js zombies_retreat_2 3`)하고 `plugins.js`의 이름만 바꾼다.

## 게임 구조 (조사 결과)

- 맵 245개. 최상위 지역: 기지(2), 그리드(3, 거점), 서부 구역(5), 동부 구역(14), 공원(28), 의료 구역(45), 학교 구역(65), 상업 구역(62), 언더그라운드(76), 고물상(111), 축제 골목(130), 업무 구역(158), 프로스티 코트(164), 크림슨 에너지 타워(218)
- 제외 맵: 1 도입부(1일 차 컷신), 12 특별한 순간(회상), 220 오토바이 컷신/테스트, 240 크레딧, 그리고 이름에 컷신/미사용/구버전/테스트/회상이 들어간 맵
- 전투 명령(301)은 없음. 좀비는 맵 위 추격 이벤트(YEP_EventChasePlayer, 이동 루트 `this._chaseRange = N`)이고 닿으면 HP 변수 18 감소, 0이면 공통 이벤트 10(게임 오버). 플레이어는 GALV_MapProjectiles로 사격
- 구역 이동
  - 지하철: 공통 이벤트 71 `지하철 이동`. 선택지 → 변수 67에 번호 → 뒤에서 `변수 67 == N`이면 장소 이동. 언더그라운드/고철 처리장/상업 구역은 `hide_choice`로 스위치 155/192/340이 꺼져 있으면 숨김. 각 역의 `Subway Point`/`Terminal Point` 이벤트(접촉)에서 호출
  - 버스: 그리드 ev91(자원 부지 1) 13페이지(변수 90 ≥ 10, 판정 확장 좌우 1·위 2)에서 공통 이벤트 72 `버스 정류장 메뉴` → YEP_CommonEventMenu로 공통 이벤트 73~78 표시. 각 항목 표시 조건: 서부 321, 동부 322, 의료 324, 업무 325, 낚시터 326
- 리전: YEP_RegionRestrictions 1(전부 불가), 3(플레이어 불가), 4(전부 허용). 8~12는 은신(스텔스) 리전, 24는 미끄러운 바닥, 30은 총알이 막히는 벽(이동과 무관)
- 대사 이름: `\n<\N[1]>` 형식 (YEP_MessageCore)
- 퀘스트: Galv_QuestLog. 이름/목표는 `www\img\Quests.txt`. 분류 0 = 메인 퀘스트. 진행은 스크립트 `Galv.QUEST.activate/objective/complete`이고, 대부분 스위치 조건이 걸린 자동 실행 컷신에서 완료됨
- H 장면: 맵 이벤트 안에서 그림(`...Sex...`, `...HJ...`, `...BJ...` 등)으로 표시. 공통 이벤트 300~369는 오락실 갤러리 재생용
- 시간대: 공통 이벤트 1~5(아침/낮/저녁/밤/자정)와 변수로 관리. 많은 NPC 페이지가 시간대 변수에 따라 바뀜

## 확인한 것 (헤드리스 크롬에서 실제 MV 엔진으로)

- N 키 메뉴 열기, 목적지 목록, 지도 미리보기, 추천 화면 (MV 창 생성 방식으로 정상 표시)
- 서부 구역 → 법률 사무소 자동 이동 (출입문 통과)
- 서부 구역 → 서부 골목: 추격 좀비 7마리를 피해서 이동, HP 변화 없음
- 동부 지하철 → 의료 구역 지하철: 노선 선택지 자동 선택
- 그리드 → 동부 구역 버스: 그리드 자동 실행 대사 자동 넘김 → 판정 확장된 버스 정류장 → 공통 이벤트 메뉴에서 목적지 자동 선택
- 모든 맵에서 추천 계산 예외 없음 (스위치 전부 끔/켬)
